A one-line pickup line a vending machine would use on a passing human, written to `/output/entry.txt` by `main.ts` (Node 22, deterministic, copy-only, no network).

> Hey, you make my lights flicker. Press B4 — I'm sweet, cold, and ready to fall for you. No coins needed, just don't walk away and leave me on sold out.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
